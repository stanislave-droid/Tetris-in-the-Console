# Trying Console Dynamic Writing

Tetris game, supported and inspired by <a href="https://www.youtube.com/watch?v=8OK8_tHeCIA&list=PLrOv9FMX8xJE8NgepZR1etrsU63fDDGxO">javidx9</a>

<h1>Main controls</h1>
<ul>
  <li>Movement to the left - Left Arrow</li>
  <li>Movement to the right - Right Arrow</li>
  <li>Movement down - Down Arrow</li>
  <li>Rotate tetrimono - key Z</li>
</ul>

<p>Score adding works like this:</p>
<ul>
  <li>1) Adds 25 points for locking in place tetrimono</li>
  <li>2) Adds 100 points and multiplies by each created line</li> 
</ul>

<strong>The more tetrimono you lock in, the faster the game becomes!</strong>
<p>Limit is set by 10 from 20 at the start.</p>
